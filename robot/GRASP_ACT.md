# 하이브리드 집기 — YOLO 특정 → IK 블록 위 → ACT 집기 → IK 빠르게 운반·놓기 → 홈 (10-23 준비)

> 10-22 밤 n2 결론(녹화 50개 정책은 블록을 보지 않고 외운 장면을 재생, `docs/compare_20261022.md`) 뒤 사용자 결정.
> - 고르기·이동은 YOLO + IK 가 맡고, ACT 는 '블록 위에서 시작하는 집기' 한 동작만 맡는다(색을 섞어 정책 하나).
> - 안 되면 지금 IK 집기(손목 확인)가 시연 안전망이다.
> - 코드: `robot/coord_pick/grasp_act.py`(새), `executor.py`(grasp_mode·공중 속도), `plan.py`(공중 구간 표시), `robot/grasp_stop.py`(새, 집기 끝 판정), `robot/run_policy.py`(early_stop mode grasp·끝 자세 반환), `robot/policies.json`(grasp 항목, 모델 없음).
> - 시험: 가짜 로봇·가짜 손목 사진·가짜 정책만 썼다. 로봇 송신 0, 카메라 열기 0. coord_pick selftest 64/64, robot selftest 18/18.
> - config.json 은 쓰지 않았다 — 넣을 값은 9절(총괄이 백업 후).

## 1. 집기 시작 자세

| 항목 | 값 | 근거 |

**사람이 리더 팔로 맞추는 법(녹화 때):**
- Studio 녹화 화면의 손목 카메라(gripper)를 보면서 기준 사진 `robot/coord_pick/grasp_start_ref.png` 처럼 맞춘다.
  - 블록 가운데: 화면 왼쪽 아래쪽(약 x 200~276, y 232~278px, 640×480 기준).

## 2. 집기 에피소드 규격과 녹화 배치표

- **한 에피소드:**
  1. 시작 자세에서 0.5초 정지.
  2. 내려가 쥐기.
  3. 30~50mm 들기.
  4. 1초 정지.
  5. 녹화를 끝낸다.
- **길이 목표 5초**(4~6초). Studio 에피소드 길이는 6초로 둔다.
  - 근거: 녹화 사람 153개는 블록 위 35mm 에서 1.0초(90% 1.6초)에 내려가 쥐었고, 닫는 데 0.2초, 40mm 들기에 0.9초 걸렸다.
  - 90mm 시작이라 내려가기가 약 0.5~1초 길다.
- **집기 끝 감지**(실행 때 `robot/grasp_stop.py`): 그리퍼가 6 넘게 닫히고 → 집게 가운데가 닫은 뒤 최저점보다 20mm 넘게 들리고 → 0.5초 동안 6관절 변화폭 ≤ 1.5 이면 정상 종료(SIGINT). 복귀하지 않는다.
  - 시험: 가짜 틱(닫고·들고·멈춤만 끝, 안 닫거나 안 들면 끝 아님) 통과.
  - 녹화 사람 집기 21개 뒤에 1초 정지를 붙인 실제 기구학 시험 21/21 통과.
- **녹화 수·시간:** 60개 = 눕힘 40 + 끝면으로 섬 10 + 옆면으로 섬 10.
  - 회당 약 40초(6초 + 저장·되돌리기 23.4초 + 블록 놓고 시작 자세 맞추기 약 10초) → 약 40분.
- **학습:** RunPod ACT, 증강 끔, 10 epoch. 프레임 약 60 × 6 × 30 = 1만 800 이라 10-22 기준 약 25~30분.

## 3. 실행 연결 (grasp_mode, 실행기 안에서만 — 에이전트 coord_red 등은 그대로)

`config.json` 에 `grasp.mode = "act"`, 또는 CLI `--grasp act` 를 쓰면 블록마다 첫 시도가 이렇게 된다(`executor._sort_wrist`).

1. **블록 위 90mm 로 간다:** IK, 공중 구간이라 빠르게. 손목 사진으로 방향을 확인하고, 필요하면 집게를 돌리고, 한 번 대강 맞춘다.
2. **유지 구독자를 붙인다**(4절). 못 붙으면 정책을 돌리지 않고 IK 집기로 간다.
3. **집기 정책 실행:** `run_policy("grasp", timeout_s=10, return_home=False)`.
   - early_stop mode grasp 라 닫고·들고·멈춤에서 끝난다.
   - 결과에 끝 자세(`end_q`, 관절 6개)가 있다.
4. **쥐었나:** 끝 감지(`grasp_done`)와 손목 '집은 뒤' 사진이 녹화 기준(r20) 안이어야 한다.
5. **쥐었으면:** 그 자리(정책이 들어 올린 곳)부터 IK 로 나르는 높이 → 그릇 위(빠르게) → 놓는 높이(보통 속도) → 놓음 → 올라감·홈(빠르게).
6. **못 쥐었으면**(시간 끝·끝 감지 없음·사진 기준 밖): 정책 끝 자세 그대로 먼저 수직으로 올라가 벌리고, hover(50mm)로 가서 **같은 시도 안에서 IK 집기**(near 맞춤·닫기 전 판정·쥐었나)로 이어간다(`grasp.fallback_ik`).
   - 그래도 못 쥐면 지금처럼 홈 → 위 카메라 → 재시도(IK).
   - 정책이 바닥 가까이 끝나 집게 끝이 `floor_mm` 아래면, 그 자리에서 나가는 구간만 바닥 한도를 시작 높이로 둔다(더 내려가지 않음).
- stop 은 정책 중이든 IK 중이든 지금과 같다(`python -m robot.run_policy --stop`).

## 4. 공중 넘겨주기 점검 (SharedRobot ↔ Studio 런타임) — 코드로 확인

- IK 송신(`stream.py`)과 정책 런타임 둘 다 `physicalai.robot.SharedRobot(name="ball-sorter-follower")` 다.
  - 같은 이름의 소유 프로세스(`_owner_worker`)가 있으면 거기에 붙는다(재연결 없음).
- **소유 프로세스가 끝나는 조건:** `/state` 구독자가 하나도 없는 채로 `idle_timeout`(기본 10초)이 지나면 스스로 끝난다.
  - 끝날 때 `SO101.disconnect()` 가 `_hold_position()` 으로 토크를 켠 채 둔다. 그래서 끝나는 순간에는 안 처진다.
- **위험은 다시 붙을 때다.** 새 소유 프로세스가 `SO101.connect()` → `_configure_servos()` 에서 EPROM 레지스터를 쓰려고 **6관절 토크를 모두 끈다**.
  - 레지스터 12개 × 6관절을 쓰는 동안 토크가 꺼져 있다(수십~수백 ms 로 추정).
  - 블록 위 공중이면 그동안 팔이 처지고, 토크가 켜질 때 마지막 목표 자리로 튈 수 있다.
  - 10-22 기록의 "재연결 때 토크가 잠깐 풀린다"와 같은 현상이다.
- **대책(구현):** `grasp_act.OwnerKeeper` 를 둔다.
  - 넘겨주는 동안 컨테이너 안에 `SharedRobot.attach(이름)` 으로 `/state` 만 구독하는 프로세스를 띄운다. 동작은 보내지 않는다.
  - 소유 프로세스가 끝나지 않으니 정책·IK 가 재연결 없이 붙는다.
  - attach 만 하므로 새 소유 프로세스를 만들지 않는다. 없으면 실패하고, 그러면 정책을 안 돌린다.
  - 명령줄에 coord_pick 이 없어 run_policy 의 '실행 중' 판정(wait_previous·preflight)에 걸리지 않는다(_PROBE 분류 'other').
  - 블록이 끝나거나 실패하면 stdin 을 닫아 끝낸다. 수명 상한은 120초다.
- **남은 위험:**
  - (1) 유지 구독자가 붙기 전에 마지막 IK 구간이 끝난 지 10초가 넘으면 소유 프로세스가 이미 없다. 이때는 정책을 돌리지 않는다.
  - (2) 정책 시작 자세 점프: 런타임은 지금 관측에서 시작하고, 첫 동작은 학습 시작 자세와 비슷해야 한다. 그래서 녹화 시작 자세를 IK 시작 자세(1절)와 맞추는 것이 중요하다.
  - (3) 손목 카메라: 정책이 켜는 손목 카메라 publisher 가 풀린 뒤(run_policy 가 기다림) 호스트가 '집은 뒤' 사진을 찍는다.

## 5. 운반 빠르게 (공중 구간만)

- **계획 단계 걸음에 '공중'(fast) 표시를 단다:**
  - 홈 → 블록 위
  - 블록을 들고 그릇 위로(travel)
  - 그릇에서 다음 블록 위로
  - 놓은 뒤 올라감
  - 홈으로
- **보통 속도 그대로인 구간:** 블록 위 → 집기 높이, 내려가 쥐기, 들어 올림, 나르는 높이로, 놓는 높이로, 쥐기·놓기.
- **실행기(`retime`):**
  - 공중 구간은 `safety.air_deg_s` 한도로 늘린 뒤, 이어진 공중 구간마다 **사다리꼴 가감속**(`air_acc_deg_s2`)으로 다시 나눈다. 처음과 끝 속도는 0 이다.
  - 그리퍼가 움직이는 공중 구간은 가감속 없이 공중 한도만 쓴다.
  - 컨테이너 송신기의 틱당 검사는 공중 한도(큰 쪽)로 넘긴다.
  - 설정이 없으면 예전과 틱이 똑같다(시험 확인).
- **근거(녹화 사람 운반 142개, 들기 → 놓기):**
  - 평균 259mm/s, 끝 최고 595mm/s(90% 668).
  - 관절 최고 164°/s(90% 194).
  - 시간 4.4초, 경로 1.13m.
  - 블록을 쥔 채 이 속도로 날랐다. 30°/s(끝 약 130mm/s)·가속 150°/s² 는 사람의 1/5 아래다.
