# 부직포볼 선별 작업 기준서 (에이전트 시험용 임시본)

> 에이전트 세션이 RAG 시험용으로 만든 임시 파일이다. 정본은 UI·문서 세션이 쓰는 `docs/standard.md` 이고, 그 파일이 생기면 에이전트는 자동으로 그쪽을 읽는다.

## 1. 대상과 구역

작업 대상은 지름 3cm 이상의 빨강·파랑 부직포볼이다. 작업대에는 투입 구역, 빨강 그릇, 파랑 그릇, 불량 그릇, 손 자리 다섯 자리가 테이프로 표시되어 있다. 투입 구역은 공을 펼쳐 놓는 A4 크기 테두리이고 그릇이 아니다.

손 자리는 사람이 손바닥을 내미는 곳이다. 로봇은 손 자리에서 손이 보일 때만 건네기 동작을 한다.

## 2. 불량 정의

### 2.1 불량 표시

검은 X 표시가 있는 볼은 색과 상관없이 불량이다. 파란 볼도 X 표시가 있으면 불량이다. X 는 어느 면이 위로 와도 보이도록 8방향에 그린다.

### 2.2 판정이 애매한 경우

X 가 흐리거나 일부만 보이면 불량으로 본다(의심되면 불량 쪽으로 분류). 찢어지거나 심하게 찌그러진 볼도 불량으로 처리한다. 색이 빨강인지 파랑인지 구분되지 않는 볼은 작업자에게 확인을 요청한다.

## 3. 처리 규칙

### 3.1 처리 순서

불량 골라내기 → 정상 빨강 옮기기 → 정상 파랑 옮기기 순서로 한다. 앞 단계가 끝날 때마다 투입 구역을 다시 세어 확인한다.

### 3.2 담는 곳

불량 볼은 색과 상관없이 불량 그릇에 담는다. 정상 빨강 볼은 빨강 그릇, 정상 파랑 볼은 파랑 그릇에 담는다.

### 3.3 실패와 재시도

로봇이 볼을 놓치면 한 번 다시 시도한다. 두 번 연속 실패하면 그 명령을 멈추고 작업자에게 알린다. 볼이 그릇 밖이나 작업대 밖으로 떨어지면 로봇을 멈추고 작업자가 손으로 투입 구역에 다시 놓는다.

### 3.4 결과 보고

작업이 끝나면 그릇별 개수를 위 카메라로 세고 작업 기록(옮긴 개수)과 대조해 보고한다. 기록과 카메라 개수가 다르면 그릇을 사람이 직접 세어 확인하고, 그릇에 다른 색이나 불량이 섞였으면 꺼내어 다시 분류한다.

## 4. 안전 수칙

로봇이 움직이는 동안에는 작업 범위 안에 손을 넣지 않는다. 건네기 때만 손 자리에 손바닥을 펴서 내민다.

위험하거나 이상한 동작이 보이면 "멈춰"라고 말한다. "멈춰"는 판단 모델을 거치지 않고 실행 중인 동작을 바로 멈춘다. 그래도 멈추지 않으면 전원 스위치를 끈다.

카메라와 그릇은 녹화 이후 옮기지 않는다. 위치가 바뀌면 개수 세기와 정책 동작이 틀어진다.
