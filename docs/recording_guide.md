# 정책 4개 녹화 가이드

> ACT 정책 4개(`pick_defect` `pick_red` `pick_blue` `handoff`)를 Physical AI Studio 로 녹화하는 절차. 정책당 50 에피소드, 모두 200개.
> 원칙 하나: **정책이 학습 때 본 장면 = 시연 때 보게 될 장면.** ACT 는 말을 듣지 않고 장면만 보고 움직이므로, 투입 구역뿐 아니라 그릇 안의 상태까지 시연과 같게 만든다.
> 원칙 둘: **ACT 는 "다 했다"를 스스로 알리지 못한다.** 실행은 시간 제한(이 정책 에피소드 길이의 90% + 3초)이 끝날 때까지 계속되고, 시간이 남으면 블록을 하나 더 집으러 갈 수 있다. 그래서 모든 에피소드를 **"놓고 → 시작 자세로 돌아와 → 1~2초 가만히"** 로 끝내 "놓고 나면 쉰다"를 가르치고, 정책 안에서 에피소드 길이를 비슷하게 맞춘다(근거: `robot/README.md` 2.1).

## 1. 녹화 순서 = 시연 순서

| 순서 | 정책 | 시연에서 부르는 말 | 녹화 예상 시간 |
|---|---|---|---|
| 1 | `pick_defect` | ① "불량품 골라내 줘" | 약 47분 |
| 2 | `pick_red` | ③ "불량 빼고 나머지 다 정리해 줘"의 1단계(따로 "분홍 블록 옮겨 줘"도 같은 정책) | 약 47분 |
| 3 | `pick_blue` | ③ 의 2단계(따로 "초록 블록 옮겨 줘") | 약 47분 |
| 4 | `handoff` | ④ "분홍 블록 하나 내 손에 줘" | 약 52분(손바닥 위 블록 치우기) |
| | | **넷 합쳐** | **약 3시간 15분** |

- **시연 순서(10-22 사용자 확정, 블록 4개 — 투입: 정상 분홍 2·정상 초록 1·불량 1)**: ① "불량품 골라내 줘"(`pick_defect` 1회) → ② "지금 배치 어때?"(배치 질문, 로봇 안 움직임) → ③ "불량 빼고 나머지 다 정리해 줘"(계획: `pick_red` 2회 → `pick_blue` 1회) → ④ "분홍 블록 하나 내 손에 줘"(`handoff` 1회) → ⑤ "결과 알려 줘". 기준서 2.4 와 같다.
- 시간 근거(`robot/README.md` 끝 "재개 (2026-10-21 밤)"): 에피소드 1개에 **15초(3.2) + 저장·되돌리기·다시 시작 23.4초(10-20 실측) = 38.4초**. 정책당 50개 + 버리는 것 약 15% ≈ 58개 × 38.4초 ≈ 37분, 정책을 바꿀 때 데이터셋 만들기·장면 바꾸기·기준 길이 잡기 약 10분. 20초로 찍을 때는 43.6초 × 58개 ≈ 42분(정책당 약 50분, 넷 약 3시간 30분)이었다. <!-- TODO: 확인 필요 — 정책 바꾸는 10분·handoff +5분은 추정 -->
- 학습도 프레임 수에 비례해 20초 때보다 약 25% 준다(`robot/README.md` 정책당 추정 1시간 42분 → 약 1시간 18분, 계산). 에피소드가 길어지면 녹화·학습이 둘 다 비례해서 는다(20초면 정책당 녹화 약 +5분, 학습 +33%).
- 이 순서로 찍으면 앞 정책의 끝 장면이 다음 정책의 시작 장면이 된다. 시연도 같은 순서로 흘러간다.
- 데이터셋 이름·Task 는 `bs_pick_defect`·`bs_pick_red`·`bs_pick_blue`·`bs_handoff`(Task 는 정책 이름), **네 개 모두 같은 Environment** 로 만든다(`robot/README.md` 5.1).
- 정책 하나의 50개가 끝나면 **바로 학습을 보낸다**(보내기 전 데스크톱 원격 트레이너가 켜져 있는지 확인). 다음 정책 녹화는 학습이 도는 동안 한다. 학습 중 Stop 은 누르지 않는다 — 모델이 남지 않는다(`robot/README.md` 5.3~5.4).
- 역할: A 는 리더 팔 조작, B 는 블록 다시 놓기·화면 감시·기록표 작성(에피소드 길이도 적는다). handoff 에서는 B 가 손 자리에 손을 내민다.

### 1.1 Studio 세션을 켜 둔 채 두지 않기
- Studio 의 원격조작·녹화·모델 실행 화면은 세션을 띄워 팔을 쥔다. 세션이 살아 있으면 에이전트의 정책 실행(`run_policy`)이 `studio_session` 으로 **거부된다**.
- 녹화 묶음이 끝나면 **바로 녹화 화면에서 ← 로 나온다.** 정책 시험·리허설·시연 때는 Studio 의 이 화면들을 열어 두지 않는다. 탭만 닫으면 세션이 45초 뒤에야 풀린다.
- 반대로 정책 실행이 끝난 뒤 10초 동안은 실행 쪽이 팔을 쥐고 있어 Studio 세션이 실패할 수 있다 → 10초 기다렸다 Studio 를 연다.

## 2. 녹화 전 체크리스트 (한 번만, 녹화 시작 후 아무것도 옮기지 않는다)

**테이프 고정**
- [ ] 작업대(흰 무광 식탁보) 네 모서리를 책상에 고정
- [ ] 로봇 베이스 클램프 고정, 리더 팔은 위 카메라 화면 밖에 둔다
- [ ] 투입 구역 A4 테두리 테이프 표시
- [ ] 분홍·초록·불량 그릇 3개 바닥을 고정하고 둘레를 테이프로 표시(밀려도 제자리로)
- [ ] 손 자리 표시(손바닥 모양이나 네모)
- [ ] 위 카메라 스탠드·집게 고정, 다섯 자리(투입 구역·그릇 3개·손 자리)가 한 화면에 들어오는지 확인
- [ ] 손목 카메라 방향 고정(나사 조임, 각도에 테이프 표시)

**카메라와 조명**
- [ ] 카메라 자동 노출·자동 화이트밸런스 끄기(흰 바탕에서 색이 흔들리지 않게)
- [ ] 조명은 녹화와 시연에 같은 것을 쓴다. 창문 햇빛이 들면 블라인드를 내린다
- [ ] Studio 카메라 이름을 **녹화 전에** 정하고 녹화 4종 내내 바꾸지 않는다(기획서는 위 `tower cam`·손목 `follow cam`, 지금 Studio 환경 `env_24` 는 `front`·`gripper`). 정책 실행 때 모델 입력 이름이 이 카메라 이름이라, 녹화 뒤에 바꾸면 `camera_map` 을 따로 적어야 한다
- [ ] 위 카메라 배경에 사람·움직이는 물건이 걸리지 않는지 확인
- [ ] 위 카메라 화면 안에 초록·분홍 매트나 물건이 있으면 치운다(비전이 블록으로 잘못 찾는다 — 가짜 초록 검출)

**기준 사진**
- [ ] 녹화 직전 위 카메라 화면과 작업대 전체 사진을 찍어 둔다. 시연 날 이 사진과 겹쳐 보며 자리를 맞춘다

**블록** (기준서 2.1~2.4·3.3)
- [ ] 분홍·초록 스펀지 수세미를 한 변 약 3cm 정육면체로 깍둑썬다. 거친 연마 층(짙은 초록색 면)은 잘라 내 여섯 면이 모두 스펀지가 되게 한다
- [ ] 크기를 비슷하게: 서로 대 보아 눈에 띄게 작거나 큰 것은 다시 자르거나 뺀다
- [ ] 개수(10-22 사용자 확정): 분홍·초록 각 7개 정도 = 정상 분홍 5 · 정상 초록 5 · 불량 분홍 2 · 불량 초록 2. 시연에는 4개(정상 분홍 2·정상 초록 1·불량 1)를 쓴다. 녹화 한 장면에는 많아야 6~8개(4.1)이고, 남는 것은 세트마다 바꿔 넣거나 눌려 상한 블록과 바꾼다
- [ ] 불량은 굵은 검은 유성매직으로 X 를 **여섯 면 전부**에, 면의 대각선을 따라 크고 굵게. 블록은 아무 면이나 위로 오므로 한 면이라도 빠지면 그 면이 위일 때 정상으로 보인다
- [ ] 예비: 흰 매직블럭(멜라민) 3cm 21개. 눌리면 모양이 돌아오지 않아 예비로만 두고 녹화·시연에 섞지 않는다

## 3. 공통 녹화 요령

### 3.1 블록 3개 깔고 연달아 3에피소드
1. 목표 블록 3개(정책마다 아래 표)를 투입 구역(또는 분홍 그릇) 안에 **매번 다른 위치로** 놓는다. 블록은 공처럼 구르지 않아 놓은 그대로가 장면이 되므로, 위치와 함께 돌려 놓은 각도(반듯이·비스듬히)도 바꾼다.
2. 에피소드 1: 팔이 **홈 자세**(팔을 접은 시작 자세)에서 1초 멈춘 뒤 출발 → 블록 1개를 집어 목적지에 놓기 → **홈 자세로 돌아와 1~2초 가만히** → 녹화 끝.
3. 블록을 건드리지 않고 바로 에피소드 2, 3 을 같은 방식으로 찍는다(남은 블록이 2개, 1개인 장면이 자연스럽게 생긴다).
4. 3개가 끝나면 B 가 블록을 꺼내 위치·각도를 바꿔 다시 깔고 다음 세트로.

- **녹화 때 리더 그리퍼는 블록에 닿을 만큼만 닫는다.** 스펀지라 더 닫으면 블록이 눌리고, ACT 는 리더가 닫은 만큼 = 그 힘을 그대로 배워 실행 때도 블록을 짓누른다.
- 50 에피소드 ≈ 17세트. 버리는 것까지 생각해 18~20세트를 잡는다.
- 시연은 블록 4개(투입: 정상 분홍 2·정상 초록 1·불량 1)다. 4절 표의 세트 시작 장면은 목표 블록을 시연보다 많게 깔아, 3연속으로 찍는 동안 **시연과 같은 장면(남은 개수)이 꼭 한 번 나오게** 짰다. 목표가 아닌 블록·그릇 안 블록도 시연 때 그 시점의 모습과 맞춘다.

### 3.2 끝 장면과 길이 — 시간 제한에 맞추기
- **모든 에피소드는 블록을 놓은 뒤 홈 자세로 돌아와 1~2초 멈춘 상태로 끝낸다.** 정책은 실행 시간이 남아도 이 "쉬는 자세"를 이어 가야 한다. 놓자마자 녹화를 끊으면 정책이 남는 시간에 다음 블록을 집으러 간다.
- 시작도 늘 홈 자세에서 한다. 실행이 끝나면 팔은 **실행을 시작한 자세**로 돌아가므로(`robot/README.md` 2.3), 녹화와 실행의 시작 자세가 같아야 한다.
- **정책 안에서 에피소드 길이를 비슷하게.** 실행 시간 제한 = 그 정책 에피소드 길이의 90% + 3초다. 길이가 들쭉날쭉하면 긴 동작은 중간에 잘리고, 짧은 동작 뒤엔 남는 시간이 길어진다.
  - 목표: **한 에피소드 15초 안팎**, 같은 정책의 에피소드끼리 ±3초 안(10-22 사용자 확정 — 시연 3분 예산과 학습 시간 단축 때문. 전에는 20초). 실행 시간 제한은 15초 × 90% + 3초 ≈ 16.5초가 된다. B 가 Studio 녹화 화면의 시간을 보고 기록표에 적는다.
  - 처음 3세트를 찍은 뒤 길이를 보고 그 정책의 기준 길이를 정한다. 기준에서 5초 넘게 벗어나면 다시 찍는다.
- 리더 팔을 움직이는 속도를 에피소드마다 비슷하게. 처음 몇 개만 천천히 하고 나중에 빨라지면 길이가 갈린다.

### 3.3 버릴 에피소드
아래에 하나라도 걸리면 그 자리에서 버리고 다시 찍는다. 버린 번호와 이유는 기록표에 적는다.
- 블록을 떨어뜨림(집었다 놓침, 그릇 밖에 떨어짐 포함)
- 블록을 두 개 집음
- 그리퍼가 블록을 눈에 띄게 짓눌러 찌그러뜨림(정책이 그 힘을 배운다)
- **조작자 손이나 리더 팔이 카메라에 보임** (지난 실습 모델이 잘 못한 원인 중 하나)
- 엉뚱한 그릇에 넣음, 목표가 아닌 블록을 집음
- 작업대·그릇·카메라가 움직임
- 홈 자세로 돌아오지 않았거나, 돌아와 멈추기 전에 녹화가 끊김
- 중간에 오래 멈칫하거나 되돌아감, 길이가 그 정책 기준에서 5초 넘게 벗어남

> handoff 의 손 자리에 내민 B 의 손은 버릴 대상이 아니다. 그 손은 정책이 보고 반응해야 할 장면이다.

## 4. 정책별 장면

### 4.1 `pick_defect` — 불량 1개를 불량 그릇으로

| | 투입 구역 | 분홍 그릇 | 초록 그릇 | 불량 그릇 |
|---|---|---|---|---|
| 세트 시작 | 정상 분홍 2 + 정상 초록 1 + **불량 3**(분홍 2·초록 1 또는 분홍 1·초록 2), 섞어서 | 비어 있음 | 비어 있음 | 비어 있음 |
| 에피소드 끝 | 불량 1개 줄어듦 | 그대로 | 그대로 | 불량 1개 늘어남 |

- 정상 블록은 그대로 두고 불량만 하나씩 뺀다. 섞인 것 중 X 를 찾아 집는 것이 이 정책이 배울 일이다. 세 번째 에피소드(불량 1 + 정상 3)가 시연 장면이다.
- 불량의 색 조합을 세트마다 바꾼다(분홍 2·초록 1, 분홍 1·초록 2). 정상 블록은 시연과 같은 분홍 2·초록 1 을 기본으로, 몇 세트는 분홍 3·초록 2 로 늘려 섞는다. 불량이 정상 블록 옆에 붙어 있는 배치도 넣는다.
- 세트가 끝나면 불량 그릇의 블록 3개를 투입 구역으로 되돌린다.

### 4.2 `pick_red` — 정상 분홍 1개를 분홍 그릇으로

| | 투입 구역 | 분홍 그릇 | 초록 그릇 | 불량 그릇 |
|---|---|---|---|---|
| 세트 시작 | **정상 분홍 3** + 정상 초록 1(몇 세트는 2) | 비어 있음 | 비어 있음 | 불량 1 (시연처럼 미리 담아 둠, 몇 세트는 2) |
| 에피소드 끝 | 분홍 1개 줄어듦 | 분홍 1개 늘어남 | 그대로 | 그대로 |

- 불량은 투입 구역에 없다(앞 단계에서 이미 빠진 장면). 분홍과 초록을 고르는 것만 배운다. 두 번째 에피소드(분홍 2 + 초록 1)가 시연 장면이다.
- 세트가 끝나면 분홍 그릇의 블록을 투입 구역으로 되돌린다.

### 4.3 `pick_blue` — 정상 초록 1개를 초록 그릇으로

| | 투입 구역 | 분홍 그릇 | 초록 그릇 | 불량 그릇 |
|---|---|---|---|---|
| 세트 시작 | **정상 초록 3** | 분홍 2 | 비어 있음 | 불량 1 |
| 에피소드 끝 | 초록 1개 줄어듦 | 그대로 | 초록 1개 늘어남 | 그대로 |

- 투입 구역에는 초록만 있다. 보이는 블록을 집기만 하면 된다. 세 번째 에피소드(초록 1)가 시연 장면이다.

### 4.4 `handoff` — 분홍 그릇의 분홍 1개를 손바닥 위로

| | 투입 구역 | 분홍 그릇 | 초록 그릇 | 불량 그릇 | 손 자리 |
|---|---|---|---|---|---|
| 세트 시작 | 비어 있음 | **분홍 3** | 초록 1 | 불량 1 | B 의 손바닥(펴서 위로) |
| 에피소드 끝 | 그대로 | 분홍 1개 줄어듦 | 그대로 | 그대로 | 손바닥 위에 블록 1개 |

- 두 번째 에피소드(분홍 그릇에 2개)가 시연 장면이다.
- B 는 녹화 시작 전에 손을 손 자리에 내밀고, 팔이 홈 자세로 돌아와 1~2초 멈출 때(녹화 끝)까지 손을 움직이지 않는다. 녹화가 끝나면 블록을 옆으로 치우고 다시 손을 내민다.
- 손 위치와 높이를 손 자리 안에서 에피소드마다 조금씩 바꾼다. 손바닥 방향(펴서 위로)은 늘 같게.
- 손이 없는 장면은 녹화하지 않는다. 손이 보일 때만 정책을 부르는 것은 에이전트가 맡는다.
