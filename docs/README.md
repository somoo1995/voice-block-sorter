## RAG 문서(standard.md·robot_manual.md·system_guide.md)를 넣는 법

- 세 문서 모두 같은 꼴: 조항 하나 = `### N.M 제목` 하나. `###` 기준으로 자르면 조각마다 조항 번호와 제목이 붙는다. 조항 번호는 문서마다 따로라서 문서 이름과 함께 인용한다("기준서 3.2", "로봇 설명서 4.3", "시스템 안내서 3.4").
- 세 문서 모두 1장은 "목적과 적용 범위"이고 내용은 2장부터다. 머리말(`>` 줄)과 1장은 근거에서 빼도 된다.
- 설명서·안내서의 숫자는 프로젝트 파일의 실측·설정값만 쓰고, 조항 끝 괄호에 출처 파일(과 절)을 적었다. 실제 구동으로 아직 확인하지 않은 것은 본문에 그렇다고 적었다.
- `rag_questions.csv` 의 `expected_doc`·`expected_clause` 에 `|` 가 있으면 정답이 여럿이다. 같은 자리끼리 짝이고(`standard|robot_manual` + `6.4|5.4` = 기준서 6.4 또는 설명서 5.4), 문서가 하나면 그 문서의 조항 중 하나(`5.1|5.2`). 어느 하나가 상위 근거에 들면 맞음으로 본다. `none` = 문서 밖 질문("문서에 없습니다"가 정답).
- 각 조항은 앞뒤 없이 읽혀도 뜻이 통하게 썼다(주어를 매번 다시 씀). 조각 앞에 `## N. 장 제목` 을 붙여 넣으면 검색이 더 잘 된다.
- 답에는 조항 번호를 인용하게 한다: "기준서 3.2(색과 불량의 관계)에 따르면 …".
- 시험 질문 예와 근거 조항: "초록 불량은 왜 불량이야?" → 3.1·3.2, "실패하면 어떻게 해?" → 5.4·5.5, "로봇이 안 멈추면?" → 6.4, "블록은 몇 센티로 잘라야 돼?" → 2.2, "X 표시는 어떻게?" → 3.3, "작업 순서?" → 5.1.

## intents.csv 규칙

- `count` 는 말에 개수가 나오면 정수, 없으면 빈칸(= null). "하나"도 개수다(`handoff` 의 "분홍 블록 하나 내 손에 줘" → 1).
- `report` 와 `question` 구분: 이번 작업의 결과·개수·기록을 묻는 말은 `report`("아까 몇 개 옮겼지?"), 기준서의 규칙을 묻는 말은 `question`.
- 일부러 넣은 함정: 띄어쓰기 없는 STT 식 문장(`불량품골라내줘`), 받아쓰기 표기 흔들림 "블럭"(`분홍블럭옮겨줘` 등 6줄, "블록"과 같은 뜻), 색 동의어(`핑크 블록 옮겨 주세요` → red, `연두색 블록 하나만…` → blue), 부정("초록색 거 말고 분홍색 거부터" → red), 줄임말(`분홍 ㄱㄱ`, `초록 고`), "멈추면"이 들어간 질문("로봇이 안 멈추면 어떻게 해야 돼?" → question, stop 아님).
- 성공 기준(기획서 7절): 25문장 중 23개 이상(92%) → 이 파일 기준으로는 87줄 중 80줄 이상(앞 63줄만 보면 58줄).

## 물체 변경 (2026-10-21 밤): 부직포볼 → 스펀지 블록 → 분홍·초록

- 물체: 스펀지 수세미를 한 변 약 3cm 로 깍둑썬 블록(거친 연마 층 제거, 크기 비슷하게). 색은 처음 빨강·파랑이었다가 같은 밤 분홍·초록(파스텔)으로 바꿈. 예비로 흰 매직블럭(멜라민) 3cm 21개(눌리면 모양이 안 돌아와 예비로만).
- 불량: 굵은 검은 유성매직 X 를 여섯 면 전부(블록은 아무 면이나 위로 온다. 공 때의 "8방향"을 대신함).
- 명령: "분홍 블록 옮겨 줘" "초록 블록 옮겨 줘" "분홍 블록 하나 내 손에 줘"(1·5번은 그대로). 받아쓰기의 "블럭"도 같은 뜻.
- 수량·시연(10-22 사용자 확정): 블록은 분홍·초록 각 7개 정도(정상 5·불량 2). 시연은 블록 4개(투입: 정상 분홍 2·정상 초록 1·불량 1)로 ① 불량품 골라내 줘 ② 지금 배치 어때? ③ 불량 빼고 나머지 다 정리해 줘 ④ 분홍 블록 하나 내 손에 줘 ⑤ 결과 알려 줘. 녹화 에피소드는 15초 안팎(같은 정책 안 ±3초).
- 색: 분홍(코드 `red_*`·`bowl_red`·`pick_red`·intent `red`), 초록(`blue_*`·`bowl_blue`·`pick_blue`·intent `blue`). 말 동의어: 분홍 = 핑크, 초록 = 녹색 = 연두. 작업대는 흰 무광 식탁보.
- 사람이 보고 듣는 말만 바꿨다. 코드 식별자(`pick_red`·`handoff`·YOLO 클래스 `red_ok` 등)는 그대로. `standard.md` 조항 번호(`### N.M`)와 제목도 그대로다.
