# 스펀지 블록 선별 작업 기준서

> 문서 번호 BS-STD-01 · 판 4 · 시행 2026-10-21 · 적용: 말로 시키는 스펀지 블록 선별 로봇(SO-ARM101 1대, 위 카메라 1대)
> 이 기준서는 로봇과 사람이 함께 따른다. 질문에 답할 때는 조항 번호로 인용한다(예: "기준서 3.2 에 따르면 …").

## 1. 목적과 적용 범위

### 1.1 목적
이 기준서는 스펀지 블록 선별 작업에서 불량을 어떻게 판정하고, 어떤 순서로 처리하고, 사람이 무엇을 지켜야 하는지 정한다.

### 1.2 적용 범위
작업대 1개 위의 투입 구역, 그릇 3개(분홍·초록·불량), 손 자리에서 SO-ARM101 로봇팔이 하는 선별·전달 작업에 적용한다. 로봇은 위 카메라로 블록을 세고, 말로 받은 명령에 따라 정책(학습된 동작)을 실행한다.

## 2. 제품

### 2.1 대상 제품
선별 대상은 파스텔 색의 분홍 스펀지 블록과 초록 스펀지 블록 두 가지다. 분홍은 "핑크", 초록은 "녹색"·"연두"라고 불러도 같고, "블럭"이라고 불러도 같다. 스펀지 블록은 주방용 스펀지 수세미를 깍둑썰어 만든 정육면체다. 다른 색의 블록이나 블록이 아닌 물체는 대상이 아니며, 작업대에 있으면 사람이 치운다.

### 2.2 크기
스펀지 블록은 한 변 약 3cm 정육면체로, 블록끼리 크기를 비슷하게 자른다. 수세미의 거친 연마 층(짙은 초록색 면)은 잘라 내어 여섯 면이 모두 같은 색 스펀지가 되게 한다. 다른 블록보다 눈에 띄게 작거나 크게 잘린 블록, 모양이 망가진 블록은 집게가 안정적으로 잡지 못하므로 투입하지 않는다.

### 2.3 정상품
검은 X 표시가 없는 분홍 블록과 초록 블록이 정상품이다. 정상 분홍 블록은 분홍 그릇에, 정상 초록 블록은 초록 그릇에 담는다.

### 2.4 기본 투입 구성
시연의 기본 구성은 투입 구역에 정상 분홍 2개, 정상 초록 1개, 불량 1개, 모두 4개다. 블록은 분홍·초록 각 7개 정도(색마다 정상 5개·불량 2개)를 준비해 녹화와 교체에 쓴다.

## 3. 불량 정의

### 3.1 불량 판정 기준
블록 면에 검은 X 표시가 보이면 그 블록은 불량이다. 불량은 색과 상관없이 모두 불량 그릇에 담는다.

### 3.2 색과 불량의 관계
불량 판정은 색보다 먼저다. 초록 블록이나 분홍 블록이라도 검은 X 표시가 있으면 불량이며, 분홍 그릇이나 초록 그릇에 담지 않는다. 그래서 "초록 불량"도 불량 그릇으로 간다.

### 3.3 X 표시 방법
불량 표시는 굵은 검은 유성매직으로 블록의 여섯 면 모두에 X 를 하나씩 그린다. 블록은 어느 면이 위로 올지 모르므로, 여섯 면에 다 그려야 어느 면이 위를 향해도 위 카메라에 X 가 보인다. X 는 면의 대각선을 따라 크고 굵게 그린다.

### 3.4 판정이 애매할 때
X 인지 얼룩인지 카메라가 확신하지 못하거나, 같은 블록이 다시 셀 때마다 불량과 정상으로 바뀌면 로봇은 그 블록을 옮기지 않고 사람에게 확인을 요청한다. 사람이 보고 불량이면 불량 그릇에 직접 넣는다.

## 4. 작업 구역

### 4.1 자리와 용도
| 자리 | 용도 |
|---|---|
| 투입 구역 | 선별 전 블록을 펼쳐 놓는 A4 크기 테두리. 그릇이 아니다 |
| 분홍 그릇 | 정상 분홍 블록을 담는다 |
| 초록 그릇 | 정상 초록 블록을 담는다 |
| 불량 그릇 | 불량 블록을 색과 상관없이 담는다 |
| 손 자리 | 사람이 손바닥을 펴서 내미는 곳. 로봇이 블록을 건네는 곳이다 |

### 4.2 자리 고정
작업대에는 흰 무광 식탁보를 깐다. 작업대, 그릇 3개, 위 카메라, 손목 카메라는 테이프로 고정하며, 작업 중에는 옮기지 않는다. 자리가 바뀌면 로봇의 정책과 카메라 구역 설정이 맞지 않게 된다.

## 5. 처리 규칙

### 5.1 처리 순서
처리 순서는 불량 먼저, 그다음 분홍, 마지막 초록이다. 불량을 먼저 빼야 색 분류 때 불량이 정상 그릇에 섞이지 않는다. 앞 단계가 끝나지 않았으면 다음 단계로 넘어가지 않는다.

### 5.2 한 번에 하나
로봇은 한 번에 블록 1개만 집는다. 두 개를 함께 집었으면 실패로 본다.

### 5.3 반복과 확인
한 번 옮길 때마다 위 카메라로 다시 세어 결과를 확인한다. 개수를 지정하지 않은 명령은 투입 구역에 그 대상이 0개가 될 때까지 반복한다. "두 개만"처럼 개수를 지정한 명령은 그 개수만큼만 옮긴다.

### 5.4 실패와 재시도
다음 중 하나면 실패다: 블록을 집지 못함, 옮기다 떨어뜨림, 두 개를 집음, 다른 그릇에 넣음, 다시 셌을 때 개수가 기대와 다름. 실패하면 같은 동작을 1회 재시도한다. 재시도도 실패하면 로봇은 멈추고 사람에게 확인을 요청한다.

### 5.5 사람 확인 요청
사람 확인을 요청할 때 로봇은 무엇이 왜 안 됐는지를 말한다(예: "분홍 블록을 두 번 집지 못했습니다. 확인해 주세요."). 사람이 상황을 정리하고 새 명령을 내릴 때까지 로봇은 움직이지 않는다.

### 5.6 손 전달
손 전달은 분홍 그릇의 정상 분홍 블록을 손 자리의 손바닥 위에 올려 주는 작업이다. 로봇은 손 자리에 손이 보일 때만 움직이고, 손이 보이지 않으면 기다린다. 기다리는 동안 로봇은 움직이지 않는다. 손을 내민 사람은 블록을 받은 뒤 손을 거둔다.

## 6. 안전 수칙

### 6.1 손 넣지 않기
로봇이 작업 중일 때는 손 자리 밖으로 작업대에 손을 넣지 않는다. 투입 구역과 그릇 3개에 손을 넣는 것은 로봇이 멈춰 있을 때만 한다.

### 6.2 "멈춰"로 즉시 정지
"멈춰"라고 말하거나 화면의 정지 버튼을 누르면 로봇은 실행 중인 동작을 즉시 멈춘다. 이 명령은 언어 모델을 거치지 않고 바로 처리된다. 위험해 보이면 망설이지 말고 먼저 "멈춰"라고 말한다.

### 6.3 멈춘 뒤 다시 시작
멈춘 뒤에는 사람이 작업대 상태(떨어진 블록, 그릇 위치, 팔 자세)를 확인하고 정리한 다음 새 명령으로 다시 시작한다. 로봇은 멈춘 동작을 스스로 이어서 하지 않는다.

### 6.4 정지되지 않을 때
"멈춰"와 정지 버튼으로 팔이 멈추지 않으면 팔로워 팔의 전원 어댑터를 뽑는다. 이때 팔이 힘을 잃고 내려앉을 수 있으므로 팔 아래에 손을 두지 않는다.

### 6.5 작업 중 금지
작업 중에는 작업대, 그릇, 카메라를 옮기지 않는다. 위 카메라 앞을 몸이나 물건으로 가리지 않는다.

## 7. 보고

### 7.1 보고 시점
작업 명령 하나가 끝날 때마다 로봇은 결과를 짧게 말한다(예: "분홍 블록 4개를 담았습니다."). "결과 알려 줘"라고 하면 전체 결과를 말하고 결과 보고서를 만든다.

### 7.2 보고 항목
결과 보고에는 다음을 넣는다.
- 그릇별 개수: 불량(분홍·초록 내역), 분홍, 초록
- 손 전달 개수, 투입 구역에 남은 개수
- 작업 기록 개수와 카메라로 센 개수, 일치 여부
- 정책별 시도 횟수와 성공 횟수
- 소요 시간(명령별, 전체)
- 사람 확인 요청 건과 그 이유
- 장치별(NPU·GPU·CPU) 추론 시간

### 7.3 보고 문장 예
"불량 1개, 분홍 1개(1개 전달), 초록 1개입니다. 시도 6회 중 5회 성공, 기록과 카메라 개수가 일치합니다."

### 7.4 기록과 카메라가 다를 때
작업 기록의 개수와 카메라로 센 개수가 다르면 다르다는 사실과 차이를 그대로 보고하고 사람에게 확인을 요청한다. 어느 한쪽 숫자로 맞춰 말하지 않는다.
