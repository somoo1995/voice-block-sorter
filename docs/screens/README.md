- 에이전트, LLM(qwen3-4b), 임베딩 라우터, 세 문서 검색(작업 기준서·로봇 운용 설명서·시스템 안내서), Whisper(NPU), Supertonic 은 진짜다.
- 위 카메라 사진과 로봇 동작만 가짜다(머리줄 배지 "비전 가짜·로봇 가짜", 장치 표 "보기 MOCK").
- 실연과 같은 시간 조건이다: 정책 1회 19초(`BALL_MOCK_POLICY_S=19`), 말은 소리 없이 음성 길이만큼 기다림(`UI_TTS_OUT=timed`, 배지 "무음(시간 맞춤)"), 블록 놓침 주입 없음(`BALL_MOCK_FAIL_AT=`).

명령은 전부 **음성 파일**(`ui/samples/demo/F1_NN.wav`, 발표 실연 음성 백업)을 마이크 칸의 "파일 올리기"로 넣었다. 녹음이 끝난 뒤와 같은 경로라서 대화창의 🎙 줄은 받아쓴 글이다.

화면은 1920 폭, 밝은 테마다. `*_running` 과 `00_ready` 는 1920×1080 한 화면이다. 끝난 장면은 1080 아래로 내려간 대화창(답·근거 줄)까지 담으려고 전체 페이지로 찍었다.

크롬은 127.0.0.1 말고는 이름 풀이를 막은 상태(와이파이 끈 것과 같음)였다. 외부 요청 0건, 콘솔 오류 0건이었다(두 번 다).

**숫자 7 장면을 블록 11개로 찍은 이유**:
- 숫자 7 은 블록 7개가 필요하다(`robot/coord_pick/digits.py`).
- 실연 장면(블록 4개)에서는 색을 말하든 안 하든 모자라 거절된다.
- 가짜 작업대의 `full` 장면(정상 분홍 4·정상 초록 4·불량 3)에서도 "분홍으로"는 분홍이 4개라 거절된다. 그래서 색 없이 "블록으로 숫자 7 만들어 줘"(`ui/samples/demo/F1_13.wav`)로 찍었다.
- 가짜 작업대는 보정 전이어도 확인("할까요?")까지 간다. 실물 작업대에서 보정 전이면 "보정 전이라 계획만 보여 드릴게요"로 끝나고 버튼은 안 뜬다(`agent/README.md` "좌표 집기(arrange)").

다시 찍기:

```bash
UI_TTS_OUT=timed BALL_MOCK=1 BALL_MOCK_SCENE=demo4 BALL_MOCK_POLICY_S=19 BALL_MOCK_FAIL_AT= ui/start_ui.sh
.venv/bin/python -m ui.screens                   # 00~10, 13 + 보고서 HTML (덮어씀, --out 다른 폴더)
UI_TTS_OUT=timed BALL_MOCK=1 BALL_MOCK_SCENE=full BALL_MOCK_POLICY_S=19 BALL_MOCK_FAIL_AT= ui/start_ui.sh
.venv/bin/python -m ui.screens --part digit      # 11·12
```

`BALL_MOCK_FAIL_AT=` 를 빼면 가짜 작업대 기본값대로 3번째 시도에서 블록을 놓쳐 ③ 에 "놓쳤어요. 한 번 더 해 볼게요."가 들어간다.
